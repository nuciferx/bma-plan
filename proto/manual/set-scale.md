# ตั้ง Scale ให้แม่นยำ

Scale = อัตราแปลง **pixel ของ PDF → เมตรจริง** ค่าผิด = พื้นที่ผิดทั้งหน้า เป็นขั้นตอนสำคัญที่สุด

## ขั้นตอน (สอบเทียบ manual)

1. คลิกปุ่ม `📐 Scale` บน ribbon (หรือกด `S`)
2. คลิก **จุดเริ่ม** ของเส้นที่รู้ระยะจริง (เช่น dimension line `10.00 ม.`)
3. คลิก **จุดปลาย** ของเส้นเดียวกัน
4. ใส่ระยะจริงเป็นเมตร (เช่น `10.0`) ในกล่อง prompt
5. ยืนยัน → status bar แสดง `Scale: 1:XXX (สอบเทียบ)`

## สามสถานะของ Scale

| สถานะ | คำอธิบาย | ความน่าเชื่อถือ |
|---|---|---|
| `manual` | ผู้ใช้ตั้งเอง | สูงสุด ★★★ |
| `auto-unverified` | ระบบเดาจาก vector PDF | กลาง — ต้องยืนยันก่อนใช้ ★★ |
| `unknown` | ไม่มีข้อมูล (raster fallback) | ต่ำ — วัดเป็น pt² เท่านั้น ★ |

## ⚠ ข้อควรระวัง

- ห้าม export XLSX ขณะ scale เป็น `auto-unverified` — ตัวเลขในรายงานจะมี `?` ติดมาด้วย
- หน้าใหม่ที่เปิดจาก PDF เดิม **ไม่ใช้ scale ของหน้าเดิม** ต้องตั้งใหม่ทุกหน้า
- ถ้าระยะ dimension line ที่ใช้สอบเทียบไม่ตรง — เปลี่ยน Scale แล้ว BMA-Plan recompute พื้นที่ทุกตัวบนหน้านั้นทันที (raw-geometry contract)

## ตัวอย่างการเลือก dimension line

✅ **ดี** — dimension line ที่ระบุระยะชัด (เช่น `10.000 ม.`)
✅ **ดี** — scale bar รูปกราฟิก (`0 5 10` ม.)
⚠️ **ระวัง** — เส้นที่ไม่ได้ระบุระยะแน่นอน (อาจ rounded)
❌ **อย่าใช้** — เส้นที่มีอักษรอย่าง `≈` หรือ `~` แสดงว่าผู้เขียนเอง round

## Multi-page

แต่ละหน้าใน PDF มี scale ของตัวเองแยกกัน เพราะ:
- หน้า site plan (`1:500`) ใหญ่กว่า floor plan (`1:100`)
- หน้า detail (`1:20`) ใหญ่กว่า section (`1:50`)

ดู `Scale Manager` (เมนู Scale) เพื่อดู scale รวมทุกหน้าเทียบกัน

## แก้ไข Scale หลังตั้งแล้ว

1. เปิด `Scale Manager` (เมนู Scale)
2. คลิกหน้าที่ต้องการ → กด `ตั้งใหม่`
3. คลิก 2 จุดใหม่ → ใส่ระยะ → ยืนยัน

> หลัง recalibrate ระบบจะ recompute พื้นที่ทุกตัวบนหน้านั้นทันที — undo ได้ผ่าน `Ctrl+Z`
