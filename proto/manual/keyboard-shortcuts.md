# คีย์ลัดทั้งหมด

## File / Project

| Key | Action |
|---|---|
| `Ctrl+S` | บันทึก project (`.bmaplan`) — Save หรือ Save As ครั้งแรก |
| `Ctrl+Shift+S` | บันทึก PDF + annotation (ทับไฟล์ต้นฉบับ) |
| `Ctrl+O` | เปิด project file |
| `Ctrl+,` | เปิด Settings/Preferences modal |

## Edit

| Key | Action |
|---|---|
| `Ctrl+Z` | Undo (ระหว่างวาด: ลบจุดล่าสุด; ไม่ระหว่างวาด: undo object) |
| `Ctrl+Y` | Redo |
| `Delete` / `Backspace` | ลบ object ที่เลือก |
| `F2` | เปลี่ยนชื่อ object ที่เลือก |
| `Esc` | ยกเลิกการวาด / ปิด menu / ปิด arc-mode |
| `Enter` | จบ polygon / path / cloud frame |

## Mode / Tool

| Key | Tool |
|---|---|
| `V` | Select |
| `H` | Pan |
| `A` | Area (polygon) — ถ้ากำลังวาดอยู่: enter arc-mode |
| `Shift+R` | Rectangle |
| `Shift+C` | Circle |
| `Shift+E` | Ellipse |
| `D` | Distance (2-point) |
| `Shift+D` | Path (continuous distance) |
| `R` | Reference line |
| `P` | Parking / marker |
| `O` | Opening (toggle) |
| `Shift+O` | Ortho-lock toggle |
| `Shift+L` | Loupe toggle |
| `L` | Land (parcel boundary) |
| `B` | Building outline |
| `N` | North arrow |

## Snap (toggle)

| Key | Snap type |
|---|---|
| `E` | Endpoint (EP) |
| `M` | Midpoint (MP) |
| `C` | Center (CT) |
| — | (Nearest/Intersection/Perpendicular/Close-polygon — เปิด/ปิดผ่าน menu) |

## Navigation

| Key | Action |
|---|---|
| `←` / `→` | หน้าก่อน / หน้าถัดไป |
| `PageUp` / `PageDown` | หน้าก่อน / หน้าถัดไป (alias) |
| `Space` (hold) | Pan ชั่วคราว |
| `F` | Fit to window |
| Mouse wheel | Zoom in/out |
| `Ctrl+B` | Toggle sidebar |
| `Ctrl+P` | Toggle perpendicular snap mode |

## During Draw

| Key | Action |
|---|---|
| `Shift` (hold) | Ortho lock (มุม 0°/90°) |
| `Alt` (hold) | Disable snap ชั่วคราว |
| `A` | (in area mode) → enter arc-mode for next edge |
| `Esc` | (in arc-mode pending) → cancel arc, continue as straight |
| `Enter` | จบ polygon / path |
| คลิกซ้ำที่จุดแรก | ปิด polygon |

## Right Panel

- คลิก object บน canvas → Properties panel แสดง field ทั้งหมด
- คลิก row บน Layers list → toggle visibility / lock
- F2 → rename ตรงที่ Properties panel
