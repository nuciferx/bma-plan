# BMA-Plan

BMA-Plan is a Phase 1 factual measurement tool for building-control plan review.

Current scope:
- Open PDF
- Project/page setup
- Manual measurement
- Site facts
- Parcel sides
- North/orientation
- semanticTag/useCategory foundation
- XLSX/PDF output support

Not in current scope:
- automatic legal pass/fail
- OCR
- AI checker
- rule engine
- FAR/OSR/setback judgment
- Project PDF Save/Load
