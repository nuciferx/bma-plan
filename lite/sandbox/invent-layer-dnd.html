Layers DnD mode

What this spike proves A

Drag the ⠿ grip. Three drop zones per 30px row:
  • top 30% → blue line = insert before (reorder, replaces ▲)
  • bottom 30% → blue line = insert after (reorder, replaces ▼)
  • middle 40% over a folder → green inset = nest into it (replaces →)
  • drop on the panel's empty area / a root row's outdent zone → move to root (replaces ←)
Only .order + .parentId mutate — both already persisted in .bmaplan. Forbidden-surface profile = CLEAN.

Auto-group preview D (toggle on)

With auto-group ON: drop a root layer onto the middle of another root layer → a new folder is auto-created wrapping both (green double-ring). This is the novel reading of "การรวมกลุ่มก็เกิดจากการแดรกแอนดรอป" — no incumbent does it. Judge: delightful or surprising?

Keyboard / touch fallback

keyboard mode ON: arrow ↑/↓ moves focus, Shift+↑/↓ reorders, → nests under preceding sibling, ← outdents. (Same model ops, no drag.) Touch works via pointer events (same code path as mouse).
