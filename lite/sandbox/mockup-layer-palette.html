＋ เพิ่มประเภทพื้นที่
ขั้น 1 — พื้นที่แบบนี้คิดยังไง? (ตัวกำหนดการคำนวณ เลือกก่อนตั้งชื่อ)
ขั้น 2 — ตั้งชื่อ
ตัวอย่างผล: รูปที่วาดเป็น "หักช่องลิฟต์" จะ −ลบออกจากยอดพื้นที่อาคารของชั้นนี้
สิ่งที่หายไปจาก UI เดิม (โดยตั้งใจ):
  1. ไม่มี tree ให้ลาก — โครงชั้นเป็นของระบบ (🔒 อ่านอย่างเดียว) แก้ป้าย/ชั้นที่ 🗂 ศูนย์หน้า ที่เดียว → บั๊กตระกูล "ลากแล้วหาย / ย้ายข้ามชั้นยอดไม่ตาม / โฟลเดอร์ un-hide เอง" ตายทั้งตระกูลเพราะไม่มีท่าให้ทำผิด
  2. ไม่มีคำว่า layer/folder/PF ให้ผู้ใช้เห็นเลย (= S-3 ใน ledger) — เหลือ "ประเภทพื้นที่" กับ "ชั้น"
  3. ไม่มีกุญแจล็อกรายแถว — เหลือ 👁 ซ่อน/แสดงพอ (แนวคิดจาก 18 → ~7)
สิ่งที่เพิ่มเข้ามา:
  1. Role เด่นก่อนชื่อ — ป้าย + บวก/− หัก ติดทุกแถว และตอนสร้างต้องเลือก "คิดยังไง" ก่อนตั้งชื่อ พร้อมประโยคพยากรณ์ผล → ปิดบั๊กร้ายแรงสุด (ตั้งชื่อ "หัก…" แต่ระบบ +)
  2. ยอดแสดงในบริบทเดียว — ต่อประเภท (ในจานสี) + ต่อชั้น (ล่าง) ส่วนยอดรวมโครงการอยู่ที่ Σ สรุปที่เดียว (= ทิศ S-5: 7 ที่ → 3 ที่)
  3. บรรทัดบริบทบนสุด ตอบ 3 คำถามตลอดเวลา: อยู่หน้าไหน/ชั้นไหน · scale ตั้งหรือยัง · กำลังวาดประเภทไหน
  4. ย้ายรูปไปประเภทอื่น = เมนูเลือกประเภท (กรองเฉพาะที่เข้ากันได้ — พื้นที่ย้ายเข้า "นับจุด" ไม่ได้ = ปิด B-8 ที่ระดับดีไซน์)
สิ่งที่ไม่เปลี่ยน: โมเดลข้อมูลข้างใต้ทั้งหมด (role/semanticTag/PF derive) — นี่คือ UI ใหม่บนสัญญาเดิม ตรงกับคำตัดสินค้างใน ledger: S-2, S-3, S-4, S-5, S-9 ถูก execute พร้อมกันอย่างสอดคล้อง
