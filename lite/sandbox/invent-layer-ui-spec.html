Risk จาก inventor

  • --line naming inversion: anchor spike ใช้ --line = น้ำเงิน accent, live ใช้ --line = สี separator. Approach D เก็บชื่อตามของ live (line=separator, accent=blue) แค่เปลี่ยน value — ไม่เกิด rename.
  • Specificity doubling: body.lt-v2 .cat ลึกกว่า .cat 1 ระดับ. ถ้า future inline-injected style จาก layer-dnd.js ไม่ scope ใต้ flag, จะ override v2 colors. Ship sprint ต้อง scope JS-inject หรือ migrate ไป layer-panel.css.
  • Canvas overlap risk: 320px panel กิน canvas working area เพิ่ม 130px (จากเดิม 190px). ใน live จริงต้องเช็คว่าหน้าจอเล็ก (≤1024px) ยังทำงานได้ — ที่ 1400px viewport เหลือ canvas ~1080px ซึ่งสบาย
