# bma-plan v2 — Scope & Sprint Plan
_2026-03-28_

## ขอบเขต (What we build)

เครื่องมือตรวจแบบอนุญาตก่อสร้าง กทม. สำหรับวิศวกรควบคุมอาคาร
Input: PDF แบบก่อสร้าง → Output: ผลตรวจ pass/fail + draft ค.1

---

## Architecture ใหม่

```
Upload PDF
    ↓
[หน้า Setup] — tag หน้า + กรอกข้อมูลเคส
    ↓
Tab 1: ผังบริเวณ    → FAR/OSR/ร่น/ที่จอดรถ
Tab 2: แปลนพื้น     → GFA/ห้อง/ทางเดิน/บันได
Tab 3: รูปด้าน/ตัด  → ความสูง/ระยะดิ่ง
Tab 4: รายละเอียด   → บันไดหนีไฟ/ประตู/ช่องระบาย
    ↓
Summary + Generate ค.1
```

## Sprint 1 — Tab ผังบริเวณ
_ตรวจ FAR/OSR/ระยะร่น/ที่จอดรถ_

### เครื่องมือใน toolbar
- วาด polygon เขตที่ดิน (สีแดง)
- วาด polygon อาคาร (มีแล้ว)
- วาด polygon ที่ว่าง/OSR
- นับที่จอดรถ (polygon สีเหลือง)

### Panel ขวา — ระยะร่น
- auto-generate แถบตาม edge ของ polygon เขตที่ดิน
- แต่ละแถบ: เลือกประเภท (ถนน/เพื่อนบ้าน/แหล่งน้ำ) + กรอกความกว้าง
- วัด perpendicular distance อัตโนมัติ → pass/fail

### ผลตรวจ
| รายการ | เกณฑ์ | อ้างอิง |
|--------|--------|---------|
| FAR | ตามโซน (zone_rules.js) | ผังเมือง กทม. 2556 |
| OSR | ที่ว่าง/GFA × 100 ≥ เกณฑ์โซน | ผังเมือง กทม. 2556 |
| ระยะร่นด้านถนน | ตามความกว้างถนน ฉ.55 ข้อ 41 | |
| ระยะร่นด้านเพื่อนบ้าน | ≥2/3 ม. ตามความสูง ฉ.55 ข้อ 50 | |
| ความสูงอาคาร | ≤ 2× ระยะราบถึงเขตถนนตรงข้าม ฉ.55 ข้อ 44 | |
| ที่จอดรถ | นับช่อง เทียบตามประเภทอาคาร | ข้อบัญญัติ กทม. 2544 |
| ถนนโดยรอบ | ≥ 6 ม. (อาคารสูง/ขนาดใหญ่พิเศษ) | ฉ.33 ข้อ 3 |

## Sprint 2 — Tab แปลนพื้น
_ตรวจพื้นที่ใช้สอย/บันได/ทางเดิน_

### เครื่องมือใน toolbar
- วาด polygon ห้อง (tag ชื่อ/ประเภท)
- วัดระยะทางเดิน
- วัดระยะจากจุดไกลสุดถึงบันได
- tag ตำแหน่งบันได

### ผลตรวจ
| รายการ | เกณฑ์ | อ้างอิง |
|--------|--------|---------|
| GFA แต่ละชั้น | รวมใส่ FAR tab 1 | |
| ความกว้างทางเดิน | ≥ 1.00/1.50 ม. | ฉ.55 ข้อ 21 |
| ขนาดห้องนอน | กว้าง ≥ 2.50 ม. พื้นที่ ≥ 8 ตร.ม. | ฉ.55 ข้อ 20 |
| พื้นที่ต่อหน่วย (อาคารอยู่อาศัยรวม) | ≥ 20 ตร.ม. | ฉ.55 ข้อ 19 |
| ระยะจากจุดไกลสุดถึงบันได | ≤ 40 ม. | ฉ.55 ข้อ 25 |
| จำนวนบันได | ตามพื้นที่ชั้นเหนือ | ฉ.55 ข้อ 24 |

## Sprint 3 — Tab รูปด้าน/รูปตัด
_ตรวจความสูง/ระยะดิ่ง_

### เครื่องมือใน toolbar
- วัดความสูงแต่ละชั้น
- วัดความสูงรวม
- วัดระยะดิ่งภายในห้อง

### ผลตรวจ
| รายการ | เกณฑ์ | อ้างอิง |
|--------|--------|---------|
| ระยะดิ่ง — ที่พักอาศัย/ทางเดิน | ≥ 2.60 ม. | ฉ.55 ข้อ 22 |
| ระยะดิ่ง — สำนักงาน/ห้องเรียน | ≥ 3.00 ม. | ฉ.55 ข้อ 22 |
| ระยะดิ่ง — ห้องแถว ชั้นล่าง | ≥ 3.50 ม. | ฉ.55 ข้อ 22 |
| ระยะดิ่ง — ห้องน้ำ | ≥ 2.00 ม. | ฉ.55 ข้อ 22 |
| ความสูงรวม vs ระยะร่น | ≤ 2× ระยะราบ | ฉ.55 ข้อ 44 |
| ราวกันตก ระเบียง | ≥ 0.90 ม. | ข้อบัญญัติ กทม. |

## Sprint 4 — Tab รายละเอียด
_ตรวจบันได/หนีไฟ/ประตู_

### เครื่องมือใน toolbar
- วัดความกว้างบันได
- วัดลูกตั้ง/ลูกนอน
- วัดขนาดประตูหนีไฟ
- วัดช่องระบายอากาศ

### ผลตรวจ
| รายการ | เกณฑ์ | อ้างอิง |
|--------|--------|---------|
| กว้างบันได (พื้นที่ ≤300 ตร.ม.) | ≥ 1.20 ม. | ฉ.55 ข้อ 24 |
| กว้างบันได (พื้นที่ >300 ตร.ม.) | ≥ 1.50 ม. | ฉ.55 ข้อ 24 |
| ลูกตั้ง | ≤ 18 ซม. | ฉ.55 ข้อ 24 |
| ลูกนอน | ≥ 25 ซม. | ฉ.55 ข้อ 24 |
| บันไดหนีไฟ (≥4 ชั้น) | ≥ 1 แห่ง กว้าง ≥ 80 ซม. | ฉ.55 ข้อ 27-29 |
| ระยะห่างบันไดหนีไฟ | ≤ 60 ม. | ข้อบัญญัติ กทม. ข้อ 44 |
| ประตูหนีไฟ | กว้าง ≥ 80 ซม. สูง ≥ 190 ซม. | ข้อบัญญัติ กทม. ข้อ 45 |
| ช่องระบายอากาศบันไดหนีไฟ | ≥ 1.40 ตร.ม./ชั้น | ข้อบัญญัติ กทม. ข้อ 42 |
| ดาดฟ้า (อาคารสูง) | ≥ 10×10 ม. | ฉ.33 ข้อ 29 |

## สิ่งที่ไม่อยู่ใน scope นี้

- BEC (ประหยัดพลังงาน) — ซับซ้อนมาก ทำแยก

- รายการคำนวณโครงสร้าง — ดูจากเอกสาร ไม่ใช่แบบ
- Multi-user session — ทำหลัง v2 เสร็จ
