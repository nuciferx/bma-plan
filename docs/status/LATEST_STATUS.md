## Active Feature State (2026-05-17 — INV-freeform-area)

- **Freeform area measurement (Alt sub-mode)**: In `mode==='area'`, holding `Alt` at `mousedown` sets `mFreehandActive=true`. Subsequent `mousemove` events sample raw PDF coordinates into `mFreehandRaw` when distance from `mFreehandLastSampled` >= `freehandSampleStepPx` (6 px gate). An explicit `early-return` fires BEFORE the snap branch, so `buildSnapIndex`/`snap` are bypassed entirely during drag. On `mouseup`, `rdpSimplify(mFreehandRaw, freehandTolerance)` decimates the burst; decimated points are converted to PDF coords via `cToPdf` and pushed into `mPts` (first point skipped to avoid duplicate vertex). Releasing `Alt` before mousedown keeps the polygon in normal click-vertex mode — mixed click+drag in a single polygon is fully supported. During burst, `redraw()` draws a red dashed trail from `mFreehandRaw[0]` through all raw samples. `Shift` during freehand decreases `freehandTolerance` (finer decimation, more detail); `Ctrl` increases it (coarser, fewer points). `finishCurrentArea` attaches `obj.freeform = {tolerance, freehandSegments, originalSamples}` as an additive optional field when any freehand segment was used. Legacy `.bmaplan v1` files without `obj.freeform` load unchanged. `polyAreaM2` computes area on the decimated `mPts` array — zero change to that function. `PHASE_FREEFORM_OK` 7 sub-checks. full 44/44 GREEN.
