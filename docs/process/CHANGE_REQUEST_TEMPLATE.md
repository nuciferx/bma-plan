## เทมเพลต 5 ข้อ

```
1. แก้อะไร      — ปุ่ม/เมนู/ฟังก์ชันไหน (บอกชื่อที่เห็นบนจอ เช่น "ปุ่ม เปิด PDF", เมนู "Measure")
2. อยู่ตรงไหน   — เมนูบน / ribbon / panel ซ้าย / panel ขวา / canvas / status bar / summary widget
3. ตอนนี้เป็นยังไง — พฤติกรรมปัจจุบัน
4. อยากให้เป็นยังไง — พฤติกรรมที่ต้องการ
5. ทำไม         — use case / เหตุผล (สำคัญมากสำหรับฟีเจอร์ใหม่)
```

### ตัวอย่างที่ดี

> "เมนู Measure (เมนูบน) ตอนนี้ไม่มีปุ่มวัดเส้นโค้ง อยากเพิ่มเครื่องมือ pen วาด Bezier
> เพราะลูกค้ามีผังที่ขอบมน วัดด้วย polygon ไม่แม่น"

## กฎง่าย ๆ

- **ขอทีละเรื่อง** — 1 เรื่อง = 1 sprint. บอกหลายเรื่องได้ แต่ Claude จะแตกเป็นหลาย sprint
- **screenshot ช่วยได้มาก** — เรื่องตำแหน่ง/หน้าตา แคปมาเลย ดีกว่าอธิบายยาว
- **บอกอาการ ไม่ต้องบอกวิธีแก้** — เช่น "dropdown โดนทับ" พอ เผื่อต้นเหตุจริงเป็นอย่างอื่น
- **ภาษาไทยได้เลย** ไม่ต้องแปล

## สิ่งที่ Claude ทำให้อัตโนมัติหลังคุณบอก

1. echo กลับว่าเข้าใจว่าอะไร + อยู่ UI region ไหน + แตะ forbidden surface ไหม + ต้องแยก sprint ไหม
2. **รอคุณยืนยันก่อนแก้จริง** — มีจุด confirm เสมอ
3. แก้ → เทส (`py_compile` + `smoke` + `full` ถ้าจำเป็น) → อัปเดต docs
